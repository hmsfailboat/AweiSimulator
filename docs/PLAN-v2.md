# v1.2

## 1. 健康與心情平衡

**原則：恢復越來越難、消耗越來越多，錢買得到生活品質，買不到滿血。**

| 項目 | v1.1 | v1.2 |
|---|---|---|
| 恢復遞減 | 無 | 健康／心情的正向效果 × `min(1, (上限 − 目前值) / 60)` |
| 健康上限 | 100 | 35 歲後每 2 歲 −1 |
| 年齡衰退 | 無 | 健康每年：30 歲起 −1、40 歲起 −2、50 歲起 −3 |
| 生活壓力 | 成人 −4 | −4，再依職級／戰隊等級 +1～+2、負債 +4 |
| 營養補給品 | 健康 +8 | 健康 +5；連續每年購買效果遞減（耐受性） |
| 心理諮商 | 心情 +15，隨時可買 | 只有心情低於 40 時能買，心情 +12 |
| 頂級 SPA | 健康、心情 +12 | 刪除 |
| 超跑／豪宅 | 每年心情 +4／+6、健康 +4 | 享樂適應：每年效果減半；豪宅不再加健康；兩者都有每年維護費 |
| 消耗減免上限 | 70% | 50% |

平衡目標：一般玩法幸福度 S 約 15～35%，健康 S < 10%。

## 2. 金錢用途

`js/finance.js`，結算畫面新增「💰 年度收支」。

1. **所得稅**：職涯收入（薪水、獎金、直播、代言）依簡化綜所稅計算——扣除額 42 萬，級距 5% / 12% / 20% / 30% / 40%（59 萬 / 133 萬 / 266 萬 / 498 萬）。
2. **生活水準**（出社會後可隨時切換；大學生由家裡支付；職業選手住戰隊宿舍，費用減半）

   | 等級 | 每年 | 心情 |
   |---|---|---|
   | 🍜 小資 | 12 萬 | −1 |
   | 🏠 舒適 | 36 萬 | ±0 |
   | 🥂 奢華 | 150 萬 | +3 |
   | 👑 頂級 | 600 萬 | +5 |

   降級後 2 年「由奢入儉難」：每年心情 −4。
3. **房子**：🏡 買房（1,500 萬，頭期 20%，20 年房貸）免房租、生活費 −40%；🏰 豪宅、🏎️ 超跑有每年維護費。
4. **投資**（取代「投資理財」行動）：定存、指數 ETF、個股、加密貨幣，每年依報酬率與波動漲跌；胡投顧好友度夠高可「代操」。
5. **雇用 NPC**：私廚阿方、保全 Corey，每年付薪水。
6. **負債與破產**：存款變負數就進入負債，年息 15%，生活壓力增加，觸發催收事件。自救：賣車／賣房、向胡投顧借錢、找哈基咩問更生。連續 3 年負債或負債超過上限 → **💸 破產結局**。
7. 賭場新增 **地下錢莊**：借 50 萬，分 3 年還 90 萬。

## 3. 朋友 NPC

`js/npcs.js`、`js/data/npcs.js`，文字在 `texts.js` 的 `[npc.代號]`。

- **認識**：每年年底依人緣擲骰（`基礎 × (0.5 + 人緣/100)`），當年有開黑、網咖、交朋友類行動機率更高。開黑朋友 9 歲起可認識；胡投顧 15 歲起。
- **好友度**（0～100）：認識時 30。新行動「🎮 揪團開黑」讓所有已認識的開黑朋友好友度上升（人緣越高漲越多）；每年自然 −3（人緣 ≥ 60 只 −1）。
- 左側面板「👥 朋友」：好友度、介紹、雇用。

| NPC | 學生期 | 出社會 | 特殊功能 |
|---|---|---|---|
| 💹 胡投顧 | 教阿維存錢 | 每年「明牌」事件，好友度越高越準 | 投資代操、負債時借錢 |
| 🏛️ 哈基咩 | 開黑隊友，打不好時可以「噴他」或「Carry 他」 | 房貸繳不出來向阿維借錢 | 負債時教阿維申請更生 |
| 🎯 王選手 | FPS 勁敵 | **電競宿敵**；工程師路線：硬體公司員工價 | 職業賽場上有名字的對手 |
| 🍳 阿方 | 開黑隊友 | 半夜煮宵夜；投資他的餐廳 | 雇用為私人廚師（需有房） |
| 🐱 長長貓 | 免費早餐；代練（有被抓風險） | 選手時期的代練誘惑 | — |
| 🛡️ Corey | 網咖被嗆時罩你 | 跟蹤狂、竊盜事件時保護你 | 雇用為保全（需有豪宅），擋掉威脅類事件 |

群體事件：六人開黑夜、婚禮伴郎團。

## 4. 工程師職場聯賽

`js/office.js`。工程師（上班、創業）每年的考績改成和電競賽季一樣的逐場動畫，共用對戰清單元件。

- **季度專案 ×4**：每季一個專案（難度 = 38 + 職級×6 + 公司等級×3 ± 6），BO3：設計審查 → 開發 → 上線。可能插入突發狀況（on-call、需求變更、神隊友支援），改變該專案難度。
- **考績**：依 KPI（贏的里程碑 + 完成的專案）給 S～D，升遷點數規則同 v1.1。
- **同期排行榜**：3 位有名字的同事，每年也會累積 KPI；拿到同期第一，升遷點數 +1。換公司時重新產生。
- **升遷答辯**：點數與能力都達標時，進行技術面試、主管面談、高層簡報 3 關，過 2 關才升遷；失敗點數減半。
- **董事會投票**：升 CEO 時 7 席董事逐票開出，過半才當選；胡投顧好友度高時固定投贊成票。
- **尾牙抽獎**：每年最後的抽獎。
- **創業**：4 季成長目標；3 季以上達標 → 募資路演（3 家創投，拿到 1 份投資意向書即晉級）。

## 5. 電競宿敵：王選手

- 阿維出道的同一年，王選手也出道，主項目和阿維相同（阿維選 DOTA 時他也轉 DOTA）。
- 王選手有自己的能力成長、戰隊等級與轉會；和阿維在同一級聯賽時，會在例行賽出現，也有機會在季後賽碰頭（🔥 宿敵對決）。
- 記錄生涯對戰成績；有賽前嗆聲、賽後擁抱、他轉會等專屬事件。

# v2.0

## 7. 章節制與人生延長

- 原有 13 個結局改為「職涯章節」，照樣收進圖鑑、給傳承點。
- 每個章節完成（世界冠軍、大老闆、退役、退休……）都會問玩家：**🎬 就此落幕**（照 v1 方式結算）或 **▶ 繼續人生**（章節獎勵入帳，進入第二幕）。
- **第二幕轉職**（約 28～64 歲）：📺 實況主（訂閱數、平台年度盛典）、📋 教練（戰術值、管理新秀，可對上王選手當教練）、🏪 創業從商（通用創業引擎：電競學院、網咖連鎖、和阿方／長長貓合夥）、🏢 集團董事長（估值、併購、收購電競戰隊）、💼 天使投資人（和胡投顧）、🎣 退休享福。
- **晚年**（65 歲起）：50 歲後每回合 2 年、65 歲後 2～3 年；健康上限持續下降；每年擲骰死亡（年齡、健康、慢性病決定）；60 歲產生遺願清單。
- **臨終與告別式**：好友度高的 NPC 來探望、選擇遺言、告別式出席名單與弔辭、墓誌銘、人生年表。
- **人生終章結局**：安詳離世、兒孫滿堂、百歲人瑞、孤獨終老、過勞猝逝、破產潦倒、傳奇人生。
- **遺產 → 傳承點**。

## 8. 更多支線

- **多位女友**：人緣 ≥ 75 時可同時交往，被抓包機率隨人數上升 → 修羅場或收心求婚（`s.love` 改為陣列）。
- **子女**：婚後可能生小孩，長大後有機會子承父業。
- **冠軍之後**：衛冕王朝、名人堂、退役賽；**大老闆之後**：惡意併購、被趕下台、東山再起。
- **中年危機**、**老將復出**。
- 新成就：時間管理大師、修羅場、浪子回頭、王朝、冠軍教練、百萬訂閱、雙冠人生、兒孫滿堂、百歲人瑞、慈善家、人生贏家、東山再起。

## 10. v2.0 平衡結果（`node tools/sim.js 500`，預設繼續人生到過世）

| 指標 | 結果 |
|---|---|
| 過世年齡中位數 | 79 歲（有錢、保養好的玩法 83 歲；爆肝玩法 69 歲） |
| 選了該職業後達成目標章節 | 實況主 19%、教練 15%、創業從商 10%、董事長 33% |
| 一局的回合數 | 約 62～66 回合（v1.2 約 32～55） |
| 人生終章 | 安詳離世最常見；孤獨終老約 20～30%；傳奇人生 1～5%（有錢就花 29%） |
| `--short`（每個章節都落幕） | 與 v1.2 相同：世界冠軍 7%、大老闆 26% |
| 傳承商店全部解鎖 | 14 局（v1.2 22 局；但每局更長，總回合數相近） |

實作重點：
- 結局分成「職涯章節」與「人生終章」（`AW.ENDINGS[id].life`）。章節完成時 `Engine.offerChapter` → 玩家選 `endHere`（照舊結算）或 `continueLife`（記錄章節、進入第二幕抉擇）。同一章節第二次達成（例如衛冕後退役）直接繼續。
- 第二幕在 `js/second.js`；年度挑戰沿用賽季動畫（教練重用 `Esports.runSeason` 的覆寫參數）。
- 快轉年份由 `Engine.silentYear` 處理被動結算（收入、理財、感情、朋友、健康、死亡），玩家不用每年點。
- 死亡機率：60 歲起 `0.5% × 1.11^(年齡−60)`，再依健康（×0.6～×2.2）、慢性病（×1.5）、健康檢查（×0.7）調整；105 歲必定離世。
