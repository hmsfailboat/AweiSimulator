# 阿維模擬器 — 實作企劃 v1.1

> **狀態**：M1～M7 已實作完成（v1.1 依 `tools/sim.js` 模擬結果調整數值，見 §11.3）。直接用瀏覽器開啟 `index.html` 即可遊玩。

> 一款以文字、圖示（emoji）與進度條呈現的網頁養成遊戲。
> 主角「阿維」（劉家維）是一位遊戲天才，玩家從 0 歲開始養成他，18 歲迎來人生分岔：
> 成為**電競選手**拚世界冠軍，或成為**工程師**拚科技公司大老闆。

---

## 1. 設計目標

| 目標 | 說明 |
|---|---|
| 零美術成本 | 全部使用文字、emoji 圖示、進度條、卡片 UI |
| 開網頁即玩 | 純 HTML/CSS/JS，無需安裝、無需打包，雙擊 `index.html` 即可遊玩，也可直接放上 GitHub Pages |
| 一局 10～20 分鐘 | 每年約 2～4 次點擊，學生期 18 年 + 職涯 10～30 年 |
| 重玩性 | 隨機事件、天賦、兩條職涯、多種結局、重生傳承（Roguelite 元素） |
| 朋友梗 | 文案帶有阿維的遊戲天才人設與台灣玩家日常（網咖、段考、補習班、開黑、排位） |

```
標題畫面
  └─ 開始新人生 ─→ 出生設定（選天賦、配置初始點數）

```

### 3.1 顯示名稱規則

### 3.2 能力值（0～100，進度條顯示）

| 圖示 | 名稱 | key | 用途 |
|---|---|---|---|
| 🎯 | FPS 遊戲能力 | `fps` | 職業檢定、FPS 選手實力 |

| 💬 | 人緣 | `social` | 團隊默契、人脈、領導力基礎、部分事件 |

> 出生時可配置的只有前五項（`fps`/`dota`/`reflex`/`study`/`social`）。

### 3.3 狀態值（0～100）

| 圖示 | 名稱 | key | 規則 |
|---|---|---|---|
| ❤️ | 健康 | `health` | 熬夜、爆肝會扣；歸零 → 「病倒」事件：下一年行動數 -1、能力小幅下降 |
| 😊 | 心情 | `mood` | 讀書、補習、壓力會扣；歸零 → 「倦怠」事件：下一年行動數 -1；心情 ≥ 70 時能力成長 +10% |

### 3.4 資源
| 圖示 | 名稱 | key | 說明 |
|---|---|---|---|
| 💰 | 金錢 | `money` | 新台幣。學生期靠零用錢與打工，職涯靠薪水/獎金/代言 |
| ⭐ | 名氣 | `fame` | 電競職涯核心：影響轉會邀約、代言、直播收入 |

### 3.5 職涯專屬數值（進入職涯時才出現）
| 職涯 | 圖示 | 名稱 | key | 初始值 |
|---|---|---|---|---|
| 電競 | 🤝 | 團隊默契 | `teamwork` | `social × 0.5` |
| 工程師 | 💻 | 技術力 | `tech` | `study × 0.4` |
| 工程師 | 👔 | 領導力 | `leader` | `social × 0.3` |

### 3.6 成長公式
```
實際成長 = 基礎值 × 天賦加成 × 年齡加成 × 心情加成 × 傳承加成 × 邊際遞減
邊際遞減 = (1 - 目前值 / 120) ^ 1.8
```
- 結果採「隨機進位」（例如 2.4 → 40% 機率得 3、60% 得 2），保留期望值，高數值時仍偶爾能 +1。
- **年齡加成**：反應力 12 歲前 ×1.3；遊戲能力 6～15 歲 ×1.15（遊戲天才的黃金期）。
- **反應力衰退**：26 歲起每年 -2～-4（「神經反射」天賦延後 2 年；「健身」行動可減半）。
- 負面數值（扣健康、扣心情）不受成長加成影響，只受天賦減免。
- 實際數值會在 `tools/sim.js` 以大量模擬調整（見 §11）。

## 5. 學生時期（0～17 歲）

### 5.1 每年流程
1. **年初事件**：從事件池依條件與權重抽 1 個（20% 機率額外 1 個）。事件可能直接生效，或提供 2～3 個選項。
2. **選擇行動**：選 N 個行動（0～5 歲 N=1，6 歲起 N=2）。每張行動卡顯示效果預覽（↑↓ 圖示）。
3. **年度結算**：套用效果、零用錢、狀態檢查（病倒/倦怠）、寫入人生紀錄、自動存檔。

### 5.2 階段與行動
| 階段 | 年齡 | 行動數 | 可用行動（節錄） |
|---|---|---|---|
| 👶 嬰幼兒 | 0～5 | 1 | 爬來爬去、看爸爸打電動、玩積木、聽床邊故事、跟鄰居小孩玩 |
| 🎒 國小 | 6～11 | 2 | 認真上課、寫評量、玩 FPS、玩 DOTA（9 歲解鎖）、打球運動、交朋友、耍廢休息 |
| 🏫 國中 | 12～14 | 2 | ＋ 補習班、網咖開黑、反應力訓練（音遊/點擊）、熬夜衝排位 |
| 🎓 高中 | 15～17 | 2 | ＋ 準備學測、參加業餘比賽、打工 |

行動資料格式：`{ id, name, icon, stages, cost, effects, desc, unlock(state) }`。
事件可暫時禁用行動（例：「爸媽沒收電腦」→ 本年度遊戲類行動不可選）。

### 5.3 零用錢
每年 +（年齡 × 500）元，6 歲起發放；「富二代」×3。

## 6. 18 歲成年檢定

| 檢定 | 門檻 | 說明 |
|---|---|---|
| 🎮 職業門檻 | `max(fps, dota) ≥ 60` 且 `reflex ≥ 42` | 達標可參加戰隊試訓 |
| 📚 升學門檻 | `study ≥ 50` | 達標可考上資工系（≥ 80 為頂大，職涯起點較好） |

**試訓成功率** = `30% + (主遊戲 − 60) × 2.5% + (反應力 − 42) × 1% + 名氣 × 0.3%`（有球探推薦再 +10%），限制在 10%～95%，以動態進度條擲骰呈現。

**分流規則**（依需求「遊戲能力達標有機會成為職業選手；若學力達標則不會成為職業選手，進入工程師職涯」解讀）：
1. 只有職業門檻達標 → 試訓。成功 → 電競職涯；失敗 → 視為兩者皆未達標。
2. 只有升學門檻達標 → 工程師職涯。
3. 兩者皆達標 → **玩家自選**：「去戰隊試訓」或「乖乖去讀大學」。試訓失敗則自動進入工程師職涯（保底）。
4. 兩者皆未達標 → **19 歲延長賽**：多一年（2 個行動，可選「重考班」或「網咖閉關」等專屬行動）後重新檢定一次；再失敗 → 結局「平凡的阿維」。

## 7. 電競選手職涯（18 歲～最晚 32 歲）

### 7.1 進入時
- 輸入名字 → 顯示名稱 `Aweiisa{name}`。
- 選擇主項目：FPS 或 DOTA（預設較高者）。主項目能力 = 「主遊戲能力」。
- 起始戰隊：依試訓表現分到 Tier 0 或 Tier 1。

### 7.2 戰隊等級
| Tier | 戰隊 | 隊友實力 | 所屬賽事 | 年薪 |
|---|---|---|---|---|
| 0 | 業餘戰隊 | 46 | 次級聯賽 | 10 萬 |
| 1 | 次級聯賽隊 | 55 | 次級聯賽 | 30 萬 |
| 2 | 職業聯賽隊 | 67 | 職業聯賽 | 80 萬 |
| 3 | 強隊 | 77 | 職業聯賽 | 200 萬 |
| 4 | 豪門戰隊 | 86 | 職業聯賽 | 500 萬 |

戰隊名稱從名稱池隨機產生（虛構隊名，例：「台北閃電狼蛛」「Formosa Dragons」）。

### 7.3 每年（每賽季）流程
1. **事件**（選手專屬事件池：粉絲、直播、緋聞、隊友衝突、外掛疑雲、贊助商…）
2. **訓練行動 ×2**：個人苦練、反應特訓、戰隊合練、研究對手、開台直播、健身、休息、接代言（名氣 ≥ 40）
3. **賽季模擬**（動態進度條，一場一場跑）：
   - **戰力** `P = 0.5 × 主遊戲 + 0.25 × 反應力 + 0.15 × 團隊默契 + 0.10 × 心情`
   - **隊伍戰力** `T = 0.45 × P + 0.55 × 隊友實力`
   - **單場勝率** `p = 1 / (1 + e^(−(T − 對手) / 6))`；BO3/BO5 以單場勝率逐局擲骰
   - **聯賽**：7 場，勝 ≥ 4 進季後賽
   - **季後賽**：八強 BO3 → 四強 BO3 → 決賽 BO5（職業聯賽對手 70 / 74 / 78；次級聯賽 52 / 56 / 60）
     - 次級聯賽冠軍 → 必定收到 Tier 2 邀約
     - 職業聯賽冠軍與亞軍 → 取得**世界賽**資格
   - **世界賽**：小組賽 3 場（對手 74 / 76 / 78，勝 ≥ 2 晉級）→ 八強 BO3（80）→ 四強 BO5（83）→ 決賽 BO5（85）
   - 賽季結果先算好，逐局動畫播完後才結算獎金與名氣（避免劇透）
4. **休賽季**：依名氣與戰績收到轉會邀約（可接受/留隊；換隊後團隊默契 ×0.7）、領年薪、名氣結算。戰力遠低於戰隊要求且戰績差 → 不續約、降一級。
5. **老化**：26 歲起反應力每年 -2～-4（健身減半），29 歲起主遊戲能力每年 -1～-2。

### 7.4 勝利與結束
- 🏆 **世界冠軍** → 真結局「世界冠軍 Aweiisa___」。
- 28 歲起可主動退役；32 歲強制退役 → 依最高成就給予結局。

## 8. 工程師職涯（18 歲～最晚 60 歲）

### 8.1 大學（18～21 歲，每年 2 行動）
認真讀書、寫程式做專題、社團活動、實習（20 歲起）、打工、打電動放鬆。
22 歲畢業求職：依 `tech`、`study`、實習經歷、頂大加成決定公司等級邀約。

### 8.2 公司等級
| 等級 | 名稱 | 薪資倍率 | 升遷速度 |
|---|---|---|---|
| 0 | 新創小公司 | ×0.8 | 快 |
| 1 | 中型軟體公司 | ×1.0 | 中 |
| 2 | 科技大廠 | ×1.5 | 慢 |

### 8.3 職級
| 職級 | 名稱 | 晉升需求（節錄） | 年薪（基準） |
|---|---|---|---|
| 0 | 初級工程師 | — | 60 萬 |
| 1 | 工程師 | tech 45 | 90 萬 |
| 2 | 資深工程師 | tech 60 | 140 萬 |
| 3 | 技術主管 | tech 65、leader 45 | 200 萬 |

| 5 | 副總裁 | leader 72、social 62 | 500 萬 |

### 8.4 每年流程
1. 事件（職場事件池：裁員潮、專案爆炸、獵頭挖角、技術債、AI 浪潮…）
2. 行動 ×2：埋頭寫 code、進修學習、帶新人、跨部門協作、應酬交際、爆肝加班、side project、投資理財、休假
3. **年度考績**：`對應能力 − 職級×6 + 績效×4 + (心情−50)/5 ± 12` → S(≥75) / A(≥60) / B(≥45) / C(≥30) / D，各得升遷點數 3 / 2 / 1 / 0 / −1；升到下一級需要 2 / 3 / 4 / 6 / 8 / 10 點（× 公司升遷速度）且能力過門檻
4. 領年薪、狀態檢查、存檔

### 8.5 創業路線（另一條通往大老闆的路）
- 條件：職級 ≥ 資深工程師 且 金錢 ≥ 300 萬 → 解鎖「辭職創業」（一生最多 2 次）。
- 公司階段：🚗 車庫創業 → 🌱 種子輪 → 🅰️ A 輪 → 🅱️ B 輪 → 📈 IPO 上市 → 🏢 科技巨頭
- 每年評分 `0.4×tech + 0.35×leader + 0.25×social + 衝刺點×3 (+8 有創業點子) ± 15 − 階段×7`：≥ 58 晉級（跑道補滿 3 年）、≥ 38 持平（跑道 −1）、否則挫折（跑道 −2）；跑道歸零即倒閉。
- 倒閉 → 損失資金，回到就業市場（職級 -1）。
- 🎉 **IPO 上市** 或 **升任執行長** → 真結局「科技公司大老闆 劉家維」。

## 9. 隨機事件系統

### 9.1 資料格式
```js
{
  id: 'confiscate_pc',
  title: '爸媽沒收電腦',
  icon: '😡',
  text: '段考成績單寄到家裡……',
  phase: 'student',            // student / esports / engineer / any
  cond: s => s.age >= 9 && s.stats.study < 40,
  weight: 10,
  once: false,
  // 無 choices → 直接生效
  effects: { mood: -10 },
  flags: { noGame: 1 },        // 本年度暫時狀態
  // 或有選項
  choices: [
    { text: '乖乖認錯', effects: { mood: -5, study: 3 } },
    { text: '半夜偷玩', roll: { chance: 0.5,
        success: { text: '沒被抓到！', effects: { fps: 4 } },
        fail:    { text: '被抓包，禁足一個月', effects: { mood: -15 } } } }
  ]
}
```

| 學生時期 | 約 30 |
| 電競職涯 | 約 15 |

## 11. 技術架構

### 11.1 技術選型
- 純 HTML + CSS + 原生 JavaScript（無框架、無打包工具）。
- 以 classic `<script>` 載入，所有模組掛在全域命名空間 `window.AW`，確保直接以 `file://` 開啟也能執行。
- 隨機數使用可設定種子的 PRNG（mulberry32），存於存檔中，便於重現與測試。
- 存檔：`localStorage`
  - `awei.save.v1`：目前這一局（每年結算自動存檔）
  - `awei.meta.v1`：傳承點、升級、已解鎖天賦、成就、結局圖鑑、統計

### 11.2 檔案結構
```
AweiSimulator/
├─ index.html              入口
├─ css/style.css           樣式（深色電競風、RWD）
├─ js/
│  ├─ core.js              命名空間、RNG、工具函式、數值定義、效果套用
│  ├─ data/
│  │  ├─ traits.js         天賦
│  │  ├─ actions.js        各時期行動
│  │  ├─ events.js         隨機事件
│  │  └─ meta.js           結局、成就、傳承升級
│  ├─ engine.js            狀態機：新局、年度流程、18 歲檢定、存讀檔
│  ├─ esports.js           電競：戰隊、賽季/比賽模擬、轉會
│  ├─ engineer.js          工程師：大學、求職、考績升遷、創業
│  ├─ ui.js                畫面渲染（標題、出生、主遊戲、檢定、結局、圖鑑、商店）
│  └─ main.js              啟動
├─ tools/sim.js            Node 無頭模擬：大量自動遊玩，輸出各路線成功率供平衡
└─ docs/PLAN.md            本企劃
```

### 11.3 引擎與 UI 分離
引擎只操作純資料的 `state` 物件並回傳結果（事件、比賽紀錄、結算摘要）；UI 只負責呈現與呼叫引擎。
如此 `tools/sim.js` 可在 Node 中直接載入引擎跑上千局，驗證平衡：

| 指標 | 目標值 | v1.1 模擬結果（各 1000 局） |
|---|---|---|
| 專注遊戲：職業門檻達標率 | 60～100% | 100% |
| 專注讀書：升學門檻達標率 | 80～100% | 100% |
| 專注遊戲：世界冠軍達成率 | 15～30% | 19～22% |
| 專注讀書：大老闆（升遷路線） | 15～35% | 27～33% |
| 專注讀書：大老闆（含創業，高風險） | 25～45% | 42～44%（93% 至少倒閉一次） |
| 隨機亂玩：成年檢定雙失敗率 | 20～40% | 30～32% |

執行：`node tools/sim.js 1000`
