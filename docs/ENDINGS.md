# 結局與成就一覽

阿維模擬器所有結局、成就的達成條件與傳承點。條件以遊戲程式為準（[js/data/meta.js](../js/data/meta.js) 與各職涯模組），名稱與說明文字在 [js/data/texts.js](../js/data/texts.js)。

> 新增或修改結局、成就時，請一起更新這份文件。執行 `node tools/sim.js` 時，如果有結局或成就沒有列在這裡，會在最前面提醒。

- 結局共 **22 個**：職涯章節 17 個、人生終章 5 個。
- 成就共 **58 個**，每解鎖一個 **傳承點 +1**（一生只算一次）。

---

## 一、職涯章節（17 個）

達成章節時可以選擇 **🎬 就此落幕**（以這個章節結算）或 **▶ 繼續人生**（章節先記錄、圖鑑立即解鎖，進入人生第二幕）。標示「終點」的結局不能繼續人生。

## 四、傳承點怎麼算

每局結束時結算，可以在「🏛️ 傳承商店」購買升級與天賦。

| 項目 | 傳承點 |
|---|---|
| 平安長大成人 | 1 |
| 踏入職涯 | 2 |
| 戰隊晉升、職場升遷 | 每次 1 |
| 國內冠軍 | 第 1 座 2 點，之後每座 +1（最多 5） |
| 世界賽四強 | 3 |
| 大成就章節 | 世界冠軍、科技公司大老闆各 10；冠軍教練、百萬訂閱實況主、商業大亨各 6 |
| 第一次達成的新章節（繼續人生時） | 每個 2 |
| 繼續人生 | 每個章節 1 |
| 人生終章 | 百歲人瑞 3、傳奇人生 5、兒孫滿堂 2 |
| 成家（結局時已婚） | 2 |
| 子女 | 每個 1（最多 3） |
| 完成遺願 | 每個 1（最多 5） |
| 遺產／家產 | 每 2000 萬 1 點（最多 5） |
| 健康評等、幸福度評等 | S 2 點、A 1 點（各自計算） |
| 第一次達成的新結局 | 2 |
| 平凡的阿維（參加獎） | 1 |
| 成就 | 解鎖時每個 1（不算在結局結算裡） |

評等：一生平均 80 以上 S、70 以上 A、60 以上 B、45 以上 C，其他 D（健康以當年的健康上限換算）。
